# Smart Expense Tracker API

A FastAPI-based REST API designed for managing personal expenses. The application allows users to record, retrieve, filter, and summarize expenses, utilizing a lightweight JSON file storage layer for local data persistence.

## Features

- **Add an Expense**: Create new expense entries with title, amount, category, and date.
- **View All Expenses**: Retrieve all persisted expenses.
- **Filter Expenses by Category**: Get a filtered list of expenses (case-insensitive query matches).
- **Expense Summary**: Retrieve aggregate spend (overall total sum and breakdowns by category).
- **Delete an Expense**: Permanently remove an expense record by its unique ID.
- **Automatic Swagger Documentation**: Interactive UI documentation auto-generated by FastAPI.

## Tech Stack

- **Python** (v3.9+)
- **FastAPI**
- **Pydantic**
- **Pytest**

## Installation

To set up the project locally, follow these steps:

1. Set up a Python virtual environment:
   ```bash
   python3 -m venv venv
   ```

2. Activate the virtual environment:
   ```bash
   source venv/bin/activate
   ```

3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Run the Server

To start the FastAPI development server, run the following command:

```bash
python -m uvicorn src.main:app --reload
```

Once running, the interactive Swagger documentation will be available at:
[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## Run Tests

Run the test suite using pytest:

```bash
pytest
```
*(Note: If you run into import paths issues, invoke as `python -m pytest`.)*

## API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/expenses` | Create a new expense. |
| `GET` | `/api/expenses` | Retrieve a list of all expenses. |
| `GET` | `/api/expenses?category={category}` | Retrieve expenses filtered by category (case-insensitive). |
| `GET` | `/api/expenses/summary` | Retrieve overall sum and a category breakdown of expenses. |
| `DELETE` | `/api/expenses/{expense_id}` | Delete a specific expense by its integer ID. |
